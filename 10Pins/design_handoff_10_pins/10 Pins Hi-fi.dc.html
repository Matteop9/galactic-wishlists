02Signature element — the sweep

One device, carried everywhere: the amber phosphor scan line travelling over a glowing monitor grid. The product's moment of truth is reading the lane monitor — so the brand is the monitor's glow. The sweep appears in exactly five places; nowhere else.

X
X
X
SCANNING · 1600MS LOOP
Where it lives 1 · Processing — the sweep reads the photo, top to bottom.
2 · Verification stamp — a single sweep pass "prints" the badge onto the card.
3 · Live scoring — the current frame carries the amber underline glow.
4 · Share card — a frozen sweep line sits over the scorecard render.
5 · Splash — one pass over the wordmark on cold start. Restraint rule: the sweep never idles. It runs only while something is genuinely happening, then stops.
WORDMARK · SWAPPABLE PURE TYPE
10 PINS
The boxed numeral is the lane-number sign; the name after it is set in plain glass caps. If the name changes, only the letters change.
03Flagship components — scorecard grid, frame editor, badges, supporting set

The scorecard is the canonical brand object: glowing marks (#BFE9FF) above tabular totals, phosphor reserved for state. The 10th frame is deliberately wider (three rolls) with a heavier left rule. 4 players is the hero case; up to 8 rows stack, beyond 8 the block scrolls with the leader pinned.
