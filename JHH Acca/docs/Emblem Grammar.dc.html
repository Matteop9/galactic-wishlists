01 · THE RULE

Registers, not sprites

Every lineage owns one glyph. Tiers never redraw the glyph and never add interior detail — detail dies at 10px. Each tier adds one silhouette element to a fixed register sequence:

FLANK (beside: laurel → wings → wings + laurel) → BASE (below: chevrons) → CREST (above: rays) → FRAME (around: the laurel seals into a ring) → PLINTH (a banner beneath everything).

Tier 9+ = add one chevron to BASE per tier. Chevrons stack like rank stripes, read at any size, and the register is unbounded — no designer needed for season 15. The spoon runs the same sequence with dignity inverted; halves everywhere are left half solid + full outline at 55% (the poo, too small for strokes at 7px, flattens into a pat instead).

06 · COMPOSITION

The run rule

  1. One mark per lineage. Tiers consolidate; halves are the only companions and always sit immediately after their full mark, at the tier-1 frame.
  2. Order = descending dignity. Acca: gold → silver. Milky Bay: crown → half-crown → spoon → half-spoon.
  3. Gap = 0.3 × render height (3px at 10px).
  4. Bottom-align frames (align-items:flex-end). Every viewBox ends flush at its lowest ink, so frame-bottom is the shared baseline; crests rise from it, never hang below it.
  5. Worst legal run ≈ 48px at 10px: T8 crown + half + T8 spoon + half = 48.3px. Anything under the old grammar's 72px, most runs far under.

07 · ABOVE THE NAME

Where stacking wins: the profile header

Per the layout lab: inline stays right for leaderboards; above-the-name is for low-density spots — profile headers, winner cards — at 12–15px, max two glyphs. Consolidation is what makes this possible: one tier-6 mark crowns a name; six repeated crowns never could. Optical centring: centre horizontally on the frame (glyph centre-x is frame centre-x by construction); vertically, gap = 0.15em from frame bottom to name cap-height, then nudge the mark down by (50 − glyph-centre-y%) of its height — the per-tier value is in the handoff tables.
