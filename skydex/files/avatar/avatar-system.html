Avatar System

SkyDex · identity by combination

Rather than a fixed gallery of stock icons, every user gets one avatar built from a plane-spotter's world — aircraft and the kit around them — combined with the brand palette. Small parts, hundreds of outcomes, all unmistakably SkyDex.

01 · The maths

How we get hundreds

Three independent axes multiply. Add a fourth later (a rarity ring, a seasonal motif) and it climbs again — no new artwork required.

12 motifs  ×  8 colours  ×  3 backgrounds  = 288 unique avatars

02 · Motifs

The spotter's world

Twelve monoline glyphs: four aircraft and eight pieces of the surrounding kit — control tower, radio mast, suitcase, binoculars, windsock, compass, ticket, globe.

03 · Colour

One motif, eight schemes

Each motif recolours across the full brand palette. Same shape, completely different feel.

04 · Background

Three treatments

A plain tile, an RAF-style roundel, or the verification stamp ring — the last ties the avatar back to the core brand idea.

05 · Assigned, not chosen

Deterministic from a username

The app hashes the user ID and maps it onto the three axes, so everyone gets a stable avatar with no storage and no picker. Try a few names.
